# Dasaka

A crowdsourced bus app. Riders share live bus info, and everyone sees it in real time.

> Group project for CSIT 105, Visayas State University.

## Project Flow

1. **Decide on the idea:** agree on the problem and the MVP features.
2. **Decide on the roles:** everyone picks a role (see Team below).
3. **Decide on the design:** approve the Figma screens before coding.
4. **Decide on the tools:** choose the tech stack as a group.
5. **Use GitHub:** make tasks, branches, and pull requests (see below).
6. **Build:** each member works on their own task.
7. **Test:** try it on phone and computer, then fix bugs.
8. **Launch and present:** put it online and prepare the pitch.

## The Problem

Commuters don't know when a bus will arrive, where it is, or whether it has seats. Dasaka fixes this by letting riders share live bus info with each other.

## MVP Features

**Must have**
- Live map of nearby buses
- Bus details (route, arrival time, stops)
- Rider reports (on time, delayed, full, breakdown)
- Route list and search
- Crowding indicator

**If time allows**
- Login and profile
- Saved routes
- Report confirmation by other riders

## How to Use GitHub

1. Pick a task from the **Issues** tab.
2. Pull the latest `main`.
3. Make your own branch, e.g. `feature/bus-map`.
4. Do your work and commit.
5. Open a **Pull Request**.
6. A teammate reviews and approves it.
7. Merge into `main`.

Never commit directly to `main`.
